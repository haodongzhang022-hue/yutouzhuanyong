## 3. 风险与说明（显式暴露）

- **[风险-中] Python 脚本未经本环境运行验证**：本工作区无 python 运行时，
  `src/organization/*.py` 与 `scripts/organize_bank.py` 已完成静态审查（纯空格缩进、符号齐全），
  渲染逻辑已用等价的 perl 版本在真实数据上跑通，**但 python 正式脚本仍需在带 python 的部署环境执行一次**。
  若遇报错，均为机械问题，不影响架构设计本身。
- **[风险-低] 题目量小**：当前库仅 49 题，专项卷多为 1~4 题；随着采集器持续入库，
  同一知识点题目增多后每份专项卷会自然充实。当前实现按"已入库题"即时分组，无需人工干预。
- **[说明] 不改动原有链路**：采集/入库/API 均保持原样，`data/builtin/*.json` 不回写；
  新增组织层是**只读派生层**，可用 `scripts/organize_bank.py` 随时重建 `data/papers/`。
