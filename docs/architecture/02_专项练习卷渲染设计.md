# 02 专项练习卷渲染设计（像学生试卷那样）

> 渲染层把"规范化单题"排成**人类直接可读可做的试卷 Markdown**。
> 一份 = 一个知识点 = 一个专项练习。题目卷与解析卷分离，可转 PDF/HTML。

## 1. 试卷结构（一份专项卷）

```
┌────────────────────────────────────────────┐
│  AP Physics 1 · 专项练习 · 运动学 Kinematics │  ← 卷头
│  题型: 单选×3 ｜ 难度: easy1/med2 ｜ 题量3    │
│  建议用时: 15 分钟                            │
├────────────────────────────────────────────┤
│  一、单选题 (每题 5 分)                       │  ← 题型小节
│  1. 小球以 20 m/s 竖直上抛……(题干)           │  ← 逐题，隐藏答案
│     A. 1 s   B. 2 s   C. 3 s   D. 4 s       │
│  2. ……                                      │
├────────────────────────────────────────────┤
│  答案区（作答/自测时另行给）                   │
└────────────────────────────────────────────┘
```

## 2. 逐题渲染模板（Markdown）

单选 `mc`：
```markdown
**1.** {stem}
- A. {opt0}
- B. {opt1}
- C. {opt2}
- D. {opt3}
```

解答 `fr`：
```markdown
**{n}.** {stem}

（请写出解题过程）

---
```

公式用 LaTeX/MathJax 占位（`$...$`），便于转 PDF 时排版。

## 3. 两个文件：题目卷 vs 解析卷

- `XX_专项名.md`            → 题目卷（**不含答案/解析**，用于真实作答）
- `XX_专项名.答案与解析.md` → 解析卷（逐题含 答案 + 解题要点 + 解析）

> 这与现有 `practice_mode` 语义一致，把"做题"与"对答案"分离。

## 4. 渲染器接口契约

```python
# src/organization/paper_renderer.py
render_paper(
    catalog_topic,     # 一个知识点（kp_code, 名称, qids, 题型/难度分布）
    questions,         # 该知识点下全部规范化单题
    with_answer=False  # True→解析卷, False→题目卷
) -> str              # 返回试卷 Markdown 全文
```
